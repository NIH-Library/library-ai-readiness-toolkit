# Training Design Logic

This training model moves from shared understanding to applied judgment.

## Sequence

Awareness → Context → Responsibility → Practice → Consultation

## Description

- Awareness: Build shared understanding of what generative AI is and where it can fail.
- Context: Connect generative AI to research, library services, and local user questions.
- Responsibility: Discuss data, tools, verification, accountability, and local guidance.
- Practice: Use hands-on activities to refine prompts, add guardrails, and verify outputs.
- Consultation: Practice responding to AI-related customer questions through scenarios and triage.

## Adaptation notes

Libraries can adapt this sequence by changing the examples, tools, policies, and customer scenarios while keeping the overall progression.

# Library AI Readiness Toolkit

This toolkit provides adaptable materials for libraries developing staff training and service-readiness approaches for generative AI questions. It focuses on helping library staff move beyond basic tool awareness toward practical judgment: when to answer, verify, pause, or refer AI-related questions.

The materials were developed from an assessment-informed staff training series at the National Institutes of Health Library and generalized for adaptation in other library contexts.

## Project status

This toolkit is under active development. Initial materials include the training model, assessment item bank, verification checklist, prompt guardrails, customer conversation framework, and adaptation guidance. Additional scenarios and implementation examples will be added over time.
